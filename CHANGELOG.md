# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2025-05-10

### Added

- Initial plugin scaffold.
- MailerLite API service for creating/updating subscribers and fetching groups.
- `pmpro_after_checkout` hook integration to subscribe members on PMPro checkout.
- React-based admin settings page using `@wordpress/components`.
- REST API endpoints for reading/writing settings and fetching MailerLite groups.
